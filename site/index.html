From discovery to decisions

A connected review workflow.

01

Discover articles

Search Crossref, OpenAlex and PubMed. Use keywords, titles or a DOI; filter by year and supported journal identifiers. Inspect provider metadata and available abstracts.

02

Bring records together

Select results and import into a review project with query and retrieval provenance. Skip identifier duplicates and inspect uncertain title matches. RIS, BibTeX and CSV import also remain available.

03

Screen with context

Independent local reviewer profiles, blinding, exclusion reasons, adjudication and decision history. Open article pages or lawful open-access links; attach local PDFs for browser reading.

04

Chart and export

Custom data charting distinguishes missing information from not applicable. Export records, decisions, charting and audit history, or back up a project with its PDFs.

Your computer. Your workspace.

Start with Python.
Continue in your browser.

No third-party runtime packages are needed. Optional API keys live in the backend environment. Node.js is needed only when developing the TypeScript interface.

On Windows, use WSL or substitute py for python3. Start from the downloaded source directory if you do not use Git.

git clone https://github.com/saprimad/redreview.git
cd redreview
python3 -m src.server

Open http://127.0.0.1:8844/ on the computer running the backend.

To stop the app, press Ctrl+C in its terminal.

Know the boundaries

Discovery is one part of a review.

Document a comprehensive search strategy across the databases required by your protocol. Provider coverage and metadata vary; missing fields are labelled. No paywalls are bypassed, and full-text access is not guaranteed. Abstracts and PDFs may have separate copyright restrictions.

Reviewer profiles are local labels, not authenticated accounts. Private Tailscale access is supported when configured. Public writable hosting is not supported until authentication and user/project isolation are implemented and verified.

Review counts are defined building blocks, not a claim of PRISMA or JBI compliance. Large reviews may need additional tooling; study/report grouping is not modelled.
